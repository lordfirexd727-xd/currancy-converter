# 💱 Currency Converter

A simple and user-friendly web application that converts one currency into another using exchange rates.

## ✨ Features
- 💰 Convert currencies instantly
- 🌍 Support for multiple currencies
- 🔄 Swap currencies easily
- 📱 Clean and responsive user interface
- 📊 Real-time exchange rates (if supported by the API)

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript

## 🚀 Getting Started

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Run `index.html` in your browser.

## 🎯 Purpose

Built to practice JavaScript, API integration, currency conversion, and DOM manipulation.
